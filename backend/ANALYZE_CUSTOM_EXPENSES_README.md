# Custom Expenses Analysis Script

## Overview

The `analyze_custom_expenses.py` script analyzes all settlements in the database and generates a comprehensive report on custom expenses (expenses that don't fall into standard categories).

## What It Does

The script:
1. Queries all settlements from the database
2. Identifies custom expense categories (non-standard categories)
3. Calculates totals, averages, and statistics
4. Groups expenses by:
   - Category type (deduct, decals, custom, etc.)
   - Truck/vehicle
   - Month/year
5. Generates both a console report and JSON export

## Usage

### Prerequisites

1. Ensure you have the virtual environment activated:
```bash
cd backend
source venv/bin/activate
```

2. Make sure the database is accessible (local SQLite or Railway PostgreSQL)

### Running the Script

```bash
python3 analyze_custom_expenses.py
```

Or if the script is executable:
```bash
./analyze_custom_expenses.py
```

### Output

The script generates:

1. **Console Report** - Printed to terminal with:
   - Summary statistics
   - Breakdown by custom expense category
   - Top trucks by custom expenses
   - Monthly trends
   - Category details

2. **JSON Export** - Saved to `custom_expenses_analysis.json` with:
   - Summary data
   - Detailed category breakdowns
   - Examples for each category
   - Totals by truck and month

## Custom Expense Categories Found

Based on the analysis, the following custom expense categories are present:

1. **deduct** - Deductions from settlements (most common)
2. **decals** - Vehicle decal fees
3. **custom** - Generic custom category
4. **reimbursement** - Reimbursements (credits, not expenses - excluded from totals)

## Standard Categories (NOT Custom)

These categories are tracked separately and NOT included in custom expenses:

- fuel
- dispatch_fee
- insurance
- safety
- prepass
- ifta
- driver_pay
- payroll_fee
- loan_interest
- truck_parking
- service_on_truck
- repairs

## Troubleshooting

### ModuleNotFoundError

If you get `ModuleNotFoundError: No module named 'sqlalchemy'`:
- Activate the virtual environment: `source venv/bin/activate`
- Install dependencies: `pip install -r requirements.txt`

### Database Connection Error

- For local development: Ensure `elisgroup.db` exists in the backend directory
- For Railway: Ensure `DATABASE_URL` environment variable is set correctly

### No Custom Expenses Found

If the report shows no custom expenses:
- This is normal if all expenses are properly categorized
- Check that settlements have `expense_categories` populated
- Verify the database has settlement data
